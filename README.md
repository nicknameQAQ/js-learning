# JS 图书管理：先自己做，再对照答案

这是给你准备的完整学习项目：HTML + CSS + 原生 JavaScript。
先用浏览器本地保存数据，再做接口请求，最后可换成 Java / Spring Boot + MySQL。

你只需要 Node.js 22 或以上、浏览器和代码编辑器。当前已在 Node.js 24.9.0 上验证。
不需要 npm install，不需要数据库，不依赖在线教学接口。

## 先运行标准答案，看要做出来什么

在本文件所在目录打开 PowerShell：

```powershell
node --version
npm start
```

浏览器打开 **http://127.0.0.1:3000**。
也可以双击本目录的“启动标准答案.cmd”。
停止服务：在运行服务的终端按 Ctrl+C。

页面有“本地保存”和“接口保存”两个模式：
- 本地保存：数据在当前浏览器的 localStorage，刷新后还在。
- 接口保存：数据写入项目根目录的 `.data/books.json`，重启服务后还在。
- 两种模式的数据相互独立；切换模式不会把数据自动搬过去。
- 每种模式第一次打开都有三本示例图书，便于观察效果。
- 它是本机练习应用，没有登录或多用户权限。服务只监听 127.0.0.1。

## 给自己建一个子文件夹

例如你可以创建 `我的练习/`，初期只建三个文件：

```text
js完整项目/
├── README.md
├── 文档/                 需求、路线、接口、验收和排错
├── 参考答案/             已实现的项目和测试
└── 我的练习/             你自己新建，自己敲
    ├── index.html
    ├── style.css
    └── main.js
```

在“我的练习”目录打开一个新的 PowerShell，运行：

```powershell
node ../参考答案/server.mjs --root . --port 3001 --data-dir ./.data
```

浏览器打开 **http://127.0.0.1:3001**。
第一次还没写 index.html 时看到“页面不存在”是正常的，创建页面后再刷新。
前端用相对地址 `/api/books`，即可调用这个练习服务器的接口。
3000 是标准答案，3001 是你的练习，方便并排看效果。

你也可以把文件夹起成别的名字；上面的命令在你新建的直接子文件夹内运行即可。
不要用 file:// 双击网页来运行模块和接口练习。

## 学习节奏

每次只选一个需求：例如“显示三本图书”。
先做到可运行，再解释每个变量、函数、输入和输出，最后独立改一个小功能。
不要求一次掌握全部 JS，也不要求页面外观跟答案完全一样。

建议每完成一个阶段复制保存一个版本，或自己用 Git 提交一次。
第一阶段完成标准：你写的页面能显示三本图书，并且你能解释数据怎样变成表格。

## 检查标准答案

在项目根目录运行：

```powershell
npm test
npm run test:browser
```

第一条检查数据处理、存储和真实 HTTP 接口；没有第三方依赖。
第二条调用本机 Edge / Chrome 做浏览器交互检查，浏览器必须已安装。
也可通过环境变量 BROWSER_PATH 指向 Chromium 系浏览器的可执行文件。

本次执行结果见 [验证记录](文档/验证记录.md)。
