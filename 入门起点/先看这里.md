# 今天只做：让页面显示一本书

你现在不用从空白写完整项目，也不用先学完 HTML / CSS。
完整需求是以后要达到的目标。你从这个起点开始，每次只加一点 JS。

本文件夹的页面和样式已经准备好。
你只需要改 main.js。page-helper.js 是现成的显示工具，目前可以先不读。

## 1. 打开页面

在文件夹里双击 index.html，用 Edge / Chrome 打开。
你会看到一个空的图书卡片，这时没有录入任何书是正常的。
这个起点没有模块和接口，所以可以直接双击 HTML，不需要启动服务器。

## 2. 只学一个概念：变量

变量就是给一份数据起个名字，之后通过名字使用它。
JS 不必在变量前写 String 或 int。

下面是可在浏览器 F12 → Console 中运行的独立示例，不是今天作业的答案：

```js
const city = "上海"; // 创建一个叫 city 的变量，里面放文本“上海”。
const temperature = 26; // 创建一个叫 temperature 的变量，里面放数字 26。
console.log(city); // 输出：上海
console.log(temperature); // 输出：26
```

你现在只需要知道：
- const：声明一个之后不重新赋值的变量。
- =：把右边的值交给左边的变量。
- 文本要放在引号里，数字不用引号。
- 后面写 city 时，取到的是变量中的值；写 "city" 时，是字面上的四个字母。

不用先研究底层类型、作用域、闭包和原型。

## 3. 你的任务：自己写三行

打开 main.js，保留注释，在下面自己写：
1. 用 const 定义 title，放你喜欢的一本书的名字。
2. 用 const 定义 priceCents，放整数价格，单位为分。例如 3500 表示 35 元。
3. 调用现成的 showBook，把 title 和 priceCents 传给它。

showBook 是我准备好的“显示工具”。
调用工具的写法是：工具名字 + 括号，括号里按顺序放两个值，用英文逗号分开。
你今天只需要会使用它，后面再自己写这样的函数。

保存 main.js，回到浏览器按 Ctrl+R 刷新。
看到你填的书名和正确价格，这一步就成功了。

## 4. 再自己改一次

把书名改为另一本，把价格改为 0，保存、刷新。
能看到新书名和 0.00 元，就说明你知道怎么修改数据影响页面了。

今天到这里即可。不要顺便做表单、数据库或完整增删改查。

## 5. 卡住时怎么问

例如：
- “const 这一行怎么写？先给我一个类似例子。”
- “我不明白 title 和 \"title\" 有什么区别。”
- “我写完了但页面没变化，main.js 在这里。”

你可以在第一行就问，不需要先独立做完整个功能。
