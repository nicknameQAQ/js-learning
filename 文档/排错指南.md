# 卡住时先查什么

## 页面打不开

确认服务的终端还在运行，地址是 http://127.0.0.1:3000。
你的练习用 3001，并在自己的文件夹执行 README 的启动命令。
端口已占用时换端口，例如 npm start -- --port 3002。

看到“页面不存在”：检查 --root 指向的目录有没有 index.html。
不要把“我的练习”作为根目录启动，却期待它加载参考答案页面。

## npm / node 命令不能运行

先执行 node --version。
若 PowerShell 提示 npm.ps1 的执行策略限制，改用 npm.cmd start 或 npm.cmd test。
不需要为了本项目修改系统执行策略，也不需要 npm install。

## 点按钮没反应

F12 → Console，看第一条错误。
检查选择器是否匹配 id、脚本路径是否 404、事件是否绑定。
表单提交要考虑 preventDefault，否则浏览器会刷新页面。

## 能新增，刷新却没了

本地模式确认写了 localStorage，再确认刷新读取的是同一个键。
不要只把数据存在变量里。
3000 和 3001 是不同来源，浏览器存储彼此独立，这是正常的。

接口模式看 Network 是否真的发出请求、是否返回 2xx。
.data/books.json 是接口数据；不要在服务运行时手工修改它。

## 价格显示奇怪

先确认内部保存的是分，显示时才变成元。
0 是有效金额，不能用 if (!priceCents) 把它当作“没填”。
数字输入只要被浏览器接受，也不代表满足本项目格式规则。

## 删除错了另一条

检查你用的是 book.id，还是当前表格行号 / 数组下标。
筛选、排序、分页之后，下标和 id 通常不一致。

## 搜索出现旧结果

给输入加防抖减少请求，再为每次查询记录序号。
新查询取消旧请求；响应回来时只有最新序号才可以更新页面。
这是第七站内容，第一站可以先不做。

## 模块报错

import 路径必须匹配文件名，浏览器通常需要 .js 后缀。
HTML 引入入口脚本时用 type="module"。
通过本地 HTTP 服务打开，避免 file://。

## 保存数据报错

localStorage 可能因为浏览器隐私设置或容量限制不可写。
错误时保留表单输入，恢复环境后重试。

服务数据 JSON 损坏时会拒绝启动，并打印文件位置。
先复制文件备份，在服务停止后自己修复；确认不需要原数据时，才手工删除对应 books.json。
这属于你自己的学习数据，不会触碰知识库原始素材。
