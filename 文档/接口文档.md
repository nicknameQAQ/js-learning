# 图书管理接口约定

本项目自定义协议，可供 Node 模拟接口和未来 Java 后端共同实现。
标准答案用 fetch；axios 也能按相同协议调用，但本项目不安装它。
前端与接口同源，练习地址使用 /api/books，无需先配置 CORS。

## 数据对象与统一响应

图书：id、title、author、priceCents、available，约束见需求文档。
新增、修改请求不传 id。修改提交完整四个字段，不支持局部 PATCH。

成功（删除除外）：
```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

失败：
```json
{
  "code": 400,
  "message": "书名不能为空",
  "data": null
}
```

同时使用 HTTP 状态表达成功与失败。code: 0 是本项目成功约定，不是 Spring Boot 的统一规定。

## 1. 查询列表

GET /api/books?keyword=Java&available=all&sort=id-asc&page=1&pageSize=5

| 参数 | 默认值 | 规则 |
| --- | --- | --- |
| keyword | 空字符串 | 去空白，书名或作者子串匹配，忽略英文大小写 |
| available | all | all / true / false |
| sort | id-asc | id-asc / price-asc / price-desc / title-asc |
| page | 1 | 正整数，不超过 1000000 |
| pageSize | 5 | 整数 1～50 |

非法参数返回 400；未知查询参数忽略。
请求超过末页时，服务端将页码收拢到最后一页，空列表固定 page=1。

返回 HTTP 200：
```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "items": [
      {"id": 1, "title": "Java 入门", "author": "示例作者 A", "priceCents": 5000, "available": true}
    ],
    "total": 2,
    "page": 1,
    "pageSize": 5,
    "pages": 1,
    "stats": {"count": 2, "availableCount": 2, "totalPriceCents": 11800}
  }
}
```

items 在此只展示一条以说明结构；实际响应会返回本页全部匹配记录。
stats 按所有匹配记录计算。

## 2. 新增

POST /api/books
Content-Type: application/json

```json
{"title":"JS 项目练习","author":"学习者","priceCents":1234,"available":true}
```

HTTP 201，data 是完整图书对象，id 自动生成。

## 3. 查看单本图书

GET /api/books/1

HTTP 200，data 是图书对象。不存在返回 404。

## 4. 修改

PUT /api/books/1
Content-Type: application/json

请求体同新增。HTTP 200，data 是修改后对象，id 保持。

## 5. 删除

DELETE /api/books/1

成功 HTTP 204，响应体为空。不要无条件 response.json()。
不存在返回 404。

## 6. 重置学习数据

POST /api/reset

不需要请求体。HTTP 200，data 是恢复后的查询结果。
这是练习辅助接口，实际产品不要照搬公开重置接口。

## 常见失败

| HTTP | 意义 |
| --- | --- |
| 400 | 查询参数、字段校验或 JSON 格式错误 |
| 404 | 页面、接口或图书不存在 |
| 405 | 请求方法不支持 |
| 413 | 请求体大于 16 KiB |
| 415 | 新增 / 修改未使用 application/json |
| 500 | 服务端读写或其他内部失败 |

服务只接受本机同源写操作；没有 Origin 的本机脚本请求也可以调用。
JSON 文件写入采用临时文件替换，单进程写请求按队列执行。
不支持多个服务进程同时写同一个数据目录。两个练习进程要用不同 --data-dir。

## 对照 Java

以后写 Java 后端，可以按 Controller → Service → Repository / Mapper 拆分。
Book DTO 对应请求体，priceCents 可用 long，available 可用 boolean。
数据库 id 自增；响应保持本协议或在前端保存层里统一适配。
第一轮不必实现 Java，不要为了接接口提前增加框架。
