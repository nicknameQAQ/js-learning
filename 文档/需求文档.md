# 图书管理需求文档

版本：1.0 / 2026-10-11。目标是练 JS 语法和实际用法，不是商业系统。
本文件约定本项目行为，不依赖黑马课程的接口格式或第三方服务器。
你可以自选页面样式；功能和边界遵守本文即可。

## 1. 最终成品

一个单页图书管理工具，包含：
- 新增 / 编辑图书的表单。
- 图书列表及编辑、删除按钮。
- 按书名或作者搜索，按在售状态筛选。
- 按编号、价格或书名排序。
- 分页、筛选结果统计。
- 加载、空数据、错误和操作成功提示。
- 刷新后恢复数据。
- 本地保存 / 接口保存两种模式。

第一轮只做本地保存；接口模式放到最后。
不要求登录、上传封面、借还书、支付、Vue、Java 后端或部署。

## 2. 一条图书记录长什么样

| 字段 | 类型 | 规则 |
| --- | --- | --- |
| id | number | 唯一正整数，由保存层生成；不能直接填，也不是数组下标 |
| title | string | 去掉首尾空白后 1～100 个 JS 字符串长度单位 |
| author | string | 去掉首尾空白后 1～100 个 JS 字符串长度单位 |
| priceCents | number | 以“分”为单位的整数，0～100000000；0 元有效 |
| available | boolean | true 为在售，false 为停售；不是库存数量 |

JS 的 string.length 按 UTF-16 代码单元计数。普通汉字通常为 1，部分 emoji 为 2。
第一遍只需知道“与输入框 maxlength 一致”，不用展开 Unicode。

首次初始化的三本书（虚构练习数据，不是实际书目和市场价格）：

| id | title | author | priceCents | available |
| --- | --- | --- | --- | --- |
| 1 | Java 入门 | 示例作者 A | 5000 | true |
| 2 | JavaScript 实战 | 示例作者 B | 6800 | true |
| 3 | Python 起步 | 示例作者 C | 0 | false |

本地保存、接口保存各自初始化一次。删光数据后必须保持空列表，不自动补种子数据。
新增编号递增，已删除的编号不重用。

## 3. 新增与编辑

表单输入：书名、作者、价格（元）、是否在售。
- 书名和作者要 trim；纯空白不合格。
- 价格必填，接受 0、0.00、12、12.3、12.34、1000000.00。
- 拒绝负数、三位小数、科学计数法、逗号、字母、单独小数点及超过上限的金额。
- 为统一输入格式，01、.5、1. 也拒绝；输入 1、0.5、1.00 即可。
- 将金额精确转换成整数分；不要把 0.1 + 0.2 当作金额计算方式。
- 校验失败要说明哪个字段有问题，不写入数据。
- 允许不同 id 的书同名，不做重复书名拦截。
- 编辑先回显原数据，提交后保持原 id，支持“取消编辑”。
- 保存中禁止重复提交；失败后保留输入，允许重新提交。
- 新增成功清空表单，回到第 1 页；编辑成功退出编辑状态。

## 4. 删除

先让用户确认，取消则不改变任何数据。
确认后删除目标 id，删除成功更新列表与统计。
删除当前正在编辑的图书时，退出编辑状态。
删除末页最后一本书时，自动回到存在的上一页。
不存在的 id 要显示错误，不误删别的记录。

## 5. 搜索、筛选、排序与分页

搜索书名或作者：去首尾空白、忽略英文大小写、子串匹配；空关键词显示全部。
状态：全部 / 在售 / 停售。
排序：编号升序（默认）/ 价格升序 / 价格降序 / 书名升序。
相同价格或书名时按 id 升序，保证结果稳定。

操作顺序固定：**搜索和状态筛选 → 排序 → 统计 → 分页**。
页码从 1 开始。页面可选每页 5 / 10 / 20 本，默认 5。
修改关键词、状态、排序或每页数量，回到第 1 页。
搜索输入停顿 250ms 后查询。接口请求较慢时，旧响应不能覆盖新结果。

分页显示“第 X / Y 页”，无数据时显示第 1 / 1 页，两边按钮禁用。
筛选结果的条数与金额按所有匹配记录算，不只是当前页。
例：每页 5 本、匹配 8 本，统计应为 8 本，不是 5 本。

## 6. 页面状态与数据保存

- 请求中显示“加载中”，请求失败显示明确错误。
- 无图书或无匹配结果显示空状态。
- 页面用文本方式显示用户输入。
- 输入书名 <img src=x onerror=alert(1)>，应显示原文字，不当作 HTML 执行。
- 本地保存用 localStorage；刷新后新增、编辑、删除结果保持。
- 本地缓存损坏时显示错误，保留原数据，不直接清空或覆盖。用户确认重置后再重新初始化。
- 接口模式用本项目服务器；服务器持久化到 JSON 文件，重启后数据保持。
- 服务数据文件损坏时启动失败，提示文件位置，不静默重建覆盖。
- 模式选择记住；本地和接口数据独立，切换不自动同步。
