# 手动验收清单

你的代码结构和页面样式可以不同，用行为判断是否完成。
每阶段先测自己写的版本，再必要时对照标准答案。

## 第一站：列表

- [ ] 首次有三本书；价格 5000 分显示 50.00 元，0 分显示 0.00 元。
- [ ] 在售和停售显示正确。
- [ ] 图书 id 和页面行号不混用。

## 第二、三站：增删改

- [ ] 新增一条有效记录，数量增加 1，保存后输入清空。
- [ ] 空字符串、纯空白书名和作者被拒绝；首尾空白会去掉。
- [ ] 价格 0、0.00、12.3、12.34、1000000.00 成功。
- [ ] 价格 -1、12.345、1e2、01、.5、1.、1000000.01、空白失败。
- [ ] 同名书可新增，id 不同。
- [ ] 编辑价格和状态，刷新后保持；id 没有改变。
- [ ] 取消编辑，不改变数据。
- [ ] 取消删除不改变数据；确认删除只删除选中的 id。
- [ ] 删除正在编辑的书，表单退出编辑状态。
- [ ] 删除最大的 id 后再新增，不重用该 id。

## 第四站：查询

- [ ] “java”“JAVA”“ Java ”能找到含 Java 的书。
- [ ] 输入作者名也能搜索。
- [ ] 搜索与在售筛选组合有效。
- [ ] 清空关键词且恢复全部状态，可看到全部数据。
- [ ] 价格升序、降序正确，0 元参与排序。
- [ ] 同价记录按 id 升序；排序不改变原始存储顺序。
- [ ] 无匹配结果时有明确空状态。

## 第五站：分页与统计

- [ ] 准备至少 8 本，每页 5 本，第一页 5 本、第二页 3 本。
- [ ] 两页统计一致，按全部匹配记录统计。
- [ ] 切换关键词、状态、排序、每页数量，回到第 1 页。
- [ ] 页首禁用上一页，页末禁用下一页。
- [ ] 删除末页最后一条，回到上一页。
- [ ] 删光所有数据，保持空列表，第 1/1 页，按钮均禁用。

## 第六站：保存与边界

- [ ] 刷新后新增、编辑、删除结果保持。
- [ ] 清空列表后刷新，不恢复三条示例数据。
- [ ] 书名填 <img src=x onerror=alert(1)>，显示原文字，无弹窗。
- [ ] 本地模式中，在 F12 Console 执行下面命令再刷新，出现缓存错误且值仍为 broken：
  `localStorage.setItem("js-books-learning-v1", "broken")`
- [ ] 确认“重置当前数据”后恢复初始数据；取消重置保持原值。
- [ ] 模式选择刷新后保持，两个模式的数据互不覆盖。

## 第七站：接口

- [ ] Network 可看到 GET / POST / PUT / DELETE 请求。
- [ ] 非法请求返回 400，不存在的 id 返回 404。
- [ ] DELETE 成功为 204，没有 JSON 响应体，前端不报解析错误。
- [ ] 服务重启后，接口模式数据保持。
- [ ] 浏览器 DevTools 的 Network 切换 Offline，点击刷新，出现错误提示；恢复后可重试。
- [ ] 接口慢速时连续改变搜索词，最终显示最新条件结果。
- [ ] 请求失败时不留下“永久加载中”，提交按钮恢复可用。
- [ ] 保存过程中重复点击，不新增两本相同记录。

- [ ] 换成同一协议的 Java 后端。
