## 覆盖范围

数据规则：零金额、精确整数分、金额格式与上限、必填字段、状态类型、唯一编号。
查询：书名 / 作者、大小写、状态组合、稳定排序、不修改输入、分页与全部匹配记录统计。
保存：localStorage 刷新恢复、删空不重新初始化、损坏内容保留、写入失败恢复。
接口：真实 GET / POST / PUT / DELETE、204 空响应、400 / 404 / 405 / 413 / 415、
JSON 文件重启恢复、并发新增、落盘失败回滚与后续写操作恢复。
页面：本地与接口增删改查、非法表单、重复提交、删除确认、
删除末页最后一条、文本安全渲染、模式记忆与隔离、断网重试、
慢请求的旧结果保护、桌面与手机布局。
