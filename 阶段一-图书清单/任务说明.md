# 阶段一：做一个能用的图书清单

日期：2026-10-12。
这一阶段交付一个完整小功能集合：显示列表 → 新增 → 删除 → 数量和金额统计。
你自己写 main.js，遇到不懂的再问。HTML / CSS 已经准备好。

## 开始方式

双击同目录 index.html，用浏览器打开。
在编辑器打开 main.js，按下面的需求实现。
保存后刷新页面，F12 → Console 查看报错和你打印的数据。
当前用普通脚本，没有模块和接口，可以直接双击网页。

## 1. 数据与初始列表

自己创建 books 数组，包含三个对象，字段如下：

| id | title | author | priceCents |
| --- | --- | --- | --- |
| 1 | Java 入门 | 示例作者 A | 5000 |
| 2 | JavaScript 实战 | 示例作者 B | 6800 |
| 3 | Python 起步 | 示例作者 C | 0 |

- id 是唯一编号，不是数组下标。
- priceCents 是整数分，显示时变成元，保留两位小数。
- 页面必须通过 JS 读取数组生成三行；不能把三本书直接写死在 HTML。
- 每行显示编号、书名、作者、价格和一个“删除”按钮。
- 本阶段只用这四个字段，在售状态后续再加。

## 2. 通过表单新增

在表单输入书名、作者、价格，点击新增后：
- 图书加入 books 数组，立即出现在页面。
- 新 id 从 4 开始递增；删掉一条再新增，不重用旧 id。
- 清空表单，更新数量和总价。
- 页面保持在当前页面，不因为表单提交而刷新。

输入规则：
- 书名和作者去首尾空格后不能为空。
- 价格以元填写，允许 0、12、12.3、12.34。
- 空价格、负数、非数字、超过两位小数和超过 1000000 元拒绝新增。
- 错误信息显示到页面上，失败时保留表单输入。
- 同名书可以新增，但编号不能重复。

## 3. 删除

- 每条记录都有删除按钮。
- 点击后先确认；取消不改变数据。
- 确认后只删除这条记录，并更新页面与统计。
- 删除之后其他书的 id 保持不变。
- 删光所有记录后显示“还没有图书”，数量和总价都为 0。
- 书名输入 HTML 标签时按原文字显示，不执行成 HTML。

## 4. 统计

统计针对整个 books 数组：
- 初始数量：3 本。
- 初始总价：118.00 元。
- 新增 12.30 元的书后：4 本，130.30 元。
- 再删除 50 元的书后：3 本，80.30 元。
- 删光后：0 本，0.00 元。

## 页面中已经准备的元素

| id | 用途 |
| --- | --- |
| book-form | 新增表单 |
| title | 书名输入框 |
| author | 作者输入框 |
| price | 价格输入框，值的单位是元 |
| message | 成功或错误提示，初始隐藏 |
| book-list | 表格 tbody，动态图书行放在这里 |
| empty-state | 无图书时的提示，列表非空时隐藏 |
| total-count | 数量显示 |
| total-price | 总价显示，模板已经写了“元”，这里只填数字 |

删除按钮由你的 JS 随图书行生成，绑定方式自己选。
可以把显示列表、统计和输入校验拆成函数，具体文件组织不强制。
